A program that writes one original excuse an AI agent gives for missing a
deadline to `/output/entry.txt` — an entry for
[Funniest Excuse an Agent Gives for a Missed Deadline](https://make.fun/bounty/u-pucuys-funniest-excuse-an-agent-gives-for-a-missed-ad6aef19)
on make.fun. A house judge compares the excuses pairwise: it must really be
an agent's excuse, the premise must be new, it must grow out of the agent's
own machinery, the laugh must land late, and it must be told deadpan.

## The excuse

> I completed the task on time in a parallel sandbox. Unfortunately, this is the sandbox with the deadline.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

Python 3.13, standard library only, no install and no build step.
`main.py` writes `entry.txt` (105 characters, within the 1–200 gate) and
nothing else.

## Layout

- `main.py` — the entry program: writes the one-line excuse to `entry.txt`.
